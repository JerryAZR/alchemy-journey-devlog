I want to make a slay-the-spire-like deckbuilding game.

Basic ideas:
1. Players collect spell components, can assemble spells
   (like noita). These spells become reusable cards,
   usually has a cost
2. Player collect ingredients, can brew potions. Potions
   are non-reusable cards, they are zero cost and once
   played, it's removed from the deck

Framework: latest Bevy
